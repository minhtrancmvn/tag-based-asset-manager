## Design exploration
- Considered Arctic Technical (cool, narrow utility UI), Industrial workshop (3D printing context, high-energy markers), Warm archive (library context, quieter). Chosen **Warm workshop ledger**: searchable catalog for maker assets, calm and dense; warm stone surfaces with deep pine navigation and restrained copper accent, not a SaaS dashboard.
- Typography: Barlow Condensed 600 for wordmark/section labels; Work Sans 400/500/600 for controls and table; IBM Plex Mono 400/500 for paths/counts. Use bundled font files or Google Fonts with offline fallbacks chosen from non-banned catalog when practical; local-first means no network dependency at runtime.
- Palette: dominant `#f2efe8` warm stone / `#faf8f3` table (65%), secondary `#23372f` pine / `#dddcd3` dividers (28%), copper `#bb613b` highlights (7%); text `#233129`, muted `#68766b`, error `#a44334`, success `#416e52`. Warm floor supports workshop context. Avoid pure white/black, generic blue/purple.
- Choreography: only initial content reveal from 4px down, 260ms `cubic-bezier(0.22,1,0.36,1)`; respect reduced motion. No animated row changes or hover motion.
- Atmosphere: warm base + faint radial warm highlight + fine grid/tick texture only in sidebar/header; table remains quiet for readability.
- Manual validation: no banned fonts intentionally selected; dominance approx 65/28/7; text contrast dark green on cream > 9:1, muted on cream ~4.5:1 (verify later); restrained single entrance; layered atmosphere. Estimated score 88/100; validate visually where runtime permits.
